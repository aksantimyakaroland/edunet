# Code de Conduite — Edunet

## Notre engagement

Dans l'intérêt de favoriser un environnement inclusif et bienveillant, nous participants et mainteneurs nous engageons à rendre la participation à notre projet et à notre communauté une expérience sans harcèlement pour tous, quels que soient :

- l'âge
- la taille
- le handicap visible ou invisible
- l'ethnie
- les caractéristiques sexuelles
- l'identité et l'expression de genre
- le niveau d'expérience
- l'éducation
- le statut socio-économique
- la nationalité
- l'apparence
- la race
- la religion
- l'identité et l'orientation sexuelle

## Nos standards

Les comportements attendus qui contribuent à créer un environnement positif incluent :

✅ **Être respectueux et inclusif**
- Écouter activement les autres points de vue
- Accepter les critiques constructives
- Reconnaître et célébrer les contributions de chacun

✅ **Communiquer clairement**
- Utiliser un langage clair et accessible
- Poser des questions plutôt que de supposer
- Admettre les erreurs et apprendre des retours

✅ **Être professionnel**
- Éviter tout comportement hostile ou dégradant
- Respecter la confidentialité et la vie privée
- Donner le bénéfice du doute

## Comportements inacceptables

Les comportements suivants **ne sont pas tolérés** :

❌ **Harcèlement** — insultes, menaces, intimidation
❌ **Discrimination** — basée sur identité personnelle ou caractéristiques protégées
❌ **Contenu explicite non consentiel** — images, commentaires ou avances sexuelles
❌ **Partage d'informations privées** — adresse, numéro de téléphone sans consentement
❌ **Spam** — messages répétés, auto-promotion excessive
❌ **Sabotage** — sabotage délibéré du travail des autres ou du projet
❌ **Langage offensant** — jurons, insultes, langage discriminatoire

## Signaler un comportement inacceptable

Si vous êtes témoin ou victime d'un comportement contraire à ce code de conduite :

1. **Contact privé** → Envoyez un email à : **[email du mainteneur]**
2. **Fournissez des détails** :
   - Description du comportement
   - Personnes impliquées
   - Contexte (issue, PR, discussion)
   - Preuves si disponibles

3. **Confidentialité** → Vos signalements seront traités confidentiellement

## Application

Pour les violations avérées :

1. **Avertissement** — Pour les cas mineurs
2. **Suspension temporaire** — Accès temporairement retiré aux discussions
3. **Ban permanent** — Pour les cas graves ou répétés

Les modérateurs appliqueront ce code de conduite **équitablement et sans favoritisme**.

## Exemples concrets

### ✅ Ce qui est acceptable

```
"Je respecte votre point de vue, mais je le vois différemment basé sur..."
"Merci pour la correction ! J'ai appris quelque chose."
"Je ne suis pas d'accord, mais expliquons nos perspectives."
```

### ❌ Ce qui ne l'est pas

```
"C'est un code stupide, qui l'a écrit ?"
"Les gens comme toi ruinent ce projet."
"[contenu offensant ou explicite]"
```

## Responsabilité collective

Chaque membre de la communauté est responsable du maintien d'une atmosphère positive. Si vous voyez un comportement inacceptable, n'attendez pas — signalez-le.

## Remerciements

Ce Code de Conduite s'inspire du [Contributor Covenant](https://www.contributor-covenant.org) et de meilleures pratiques communautaires open source.
